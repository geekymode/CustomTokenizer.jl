Stepping through it

TrainStepper runs the same training one update at a time, so you can watch the tables fill in instead of waiting for a result.

using CustomTokenizer
sentences = tokenize(TOY_TEXT)
vocab     = build_vocab(sentences)
model     = Model(vocab)
pairs     = corpus_pairs(sentences, vocab; window = 2)

s = TrainStepper(model, pairs; seed = 7)
progress(s)
(update = 0, epoch = 0, pair = 0, of = 176)

When does W start moving?

Once some C column is non-zero, which happens almost immediately:

first_move = 0
while first_move == 0
    info = step!(s)
    iszero(info.ΔW) || (global first_move = progress(s).update)
end
first_move
2

How fast do the tables fill in?

reset!(s)
nonzero_C() = count(j -> !iszero(@view model.C[:, j]), 1:length(vocab))
filled = Int[]
for _ in 1:20
    step!(s)
    push!(filled, nonzero_C())
end
filled'
1×20 adjoint(::Vector{Int64}) with eltype Int64:
 4  7  10  12  12  13  14  15  16  18  18  18  18  19  19  19  20  20  20  21

Each update touches at most four C columns, so the table fills within the first few updates of the first epoch.

Bigger jumps

run_updates!(s, 25)       # 25 updates, returns the last
progress(s)
(update = 45, epoch = 1, pair = 45, of = 176)
finish_epoch!(s)          # to the end of the epoch
progress(s)
(update = 176, epoch = 1, pair = 176, of = 176)

Replaying a run

reset! restores the starting tables and rewinds the counters, so the same sequence can be replayed exactly:

reset!(s)
run_updates!(s, 100)
snapshot = copy(model.W)

reset!(s)
run_updates!(s, 100)
model.W == snapshot
true

Stepping and train! are the same rule

a = Model(vocab); sa = TrainStepper(a, pairs; seed = 99); run_updates!(sa, length(pairs))
b = Model(vocab); train!(b, pairs; epochs = 1, rng = CustomTokenizer.Xoshiro(99))
a.W ≈ b.W && a.C ≈ b.C
true

Watching a pair

Two probes tell the story: a pair that really occurs, and one that never does.

reset!(s)
watch = [("cat", "drinks"), ("cat", "king")]
for _ in 1:20
    finish_epoch!(s)
end
[(a, b, round(probability(model, a, b); digits = 3)) for (a, b) in watch]
2-element Vector{Tuple{String, String, Float64}}:
 ("cat", "drinks", 0.202)
 ("cat", "king", 0.237)
for _ in 1:100
    finish_epoch!(s)
end
[(a, b, round(probability(model, a, b); digits = 3)) for (a, b) in watch]
2-element Vector{Tuple{String, String, Float64}}:
 ("cat", "drinks", 0.458)
 ("cat", "king", 0.004)

The real pair heads for its balance point near 0.4, the impossible pair toward 0.
