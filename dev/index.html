CustomTokenizer.jl

Skip-gram word2vec with negative sampling, written to be read rather than to be fast. Every step of the algorithm is a named function you can call on its own, print, plot and test.

The package grew out of a twelve-sentence teaching script. That corpus ships as TOY_TEXT and the defaults match it, so the whole state of a run fits on one screen:

using CustomTokenizer

sentences = tokenize(TOY_TEXT)
vocab     = build_vocab(sentences)
Vocabulary: 22 words, 62 tokens
   1  the        16
   2  a          6
   3  cat        4
   4  dog        3
   5  king       3
   6  queen      3
   7  castle     2
   8  chases     2
   9  crown      2
  10  drinks     2
  ⋮  (12 more)

Nothing here is a black box. The two tables the algorithm trains are ordinary matrices you can index:

model = Model(vocab; dim = 8, window = 2, negative = 3)
round.(wordvec(model, "cat"); digits = 4)
8-element Vector{Float64}:
  0.0301
  0.0467
  0.0174
  0.0148
 -0.0089
  0.0001
 -0.0098
 -0.0267

and one training step is one function call that tells you what it did:

update_pair!(model, "cat", "drinks", ["on", "wears", "queen"], 0.5)
update: center cat · context drinks · negatives on, wears, queen · lr 0.5000
  word        want       p         g
  drinks        1    0.50000  +0.25000
  on            0    0.50000  -0.25000
  wears         0    0.50000  -0.25000
  queen         0    0.50000  -0.25000
  loss 2.77259 · |ΔW[:, cat]| 0.000e+00

After the full run, words used in the same kind of sentence end up pointing the same way:

pairs = corpus_pairs(sentences, vocab; window = 2)
train!(model, pairs; epochs = 300)

[(a, b, round(similarity(model, a, b); digits = 2)) for (a, b) in
 (("king", "queen"), ("cat", "dog"), ("milk", "water"), ("cat", "king"))]
4-element Vector{Tuple{String, String, Float64}}:
 ("king", "queen", 1.0)
 ("cat", "dog", 0.74)
 ("milk", "water", 0.78)
 ("cat", "king", 0.17)

Plotting lives in a package extension: the core package has no dependencies beyond the standard library, and the plotting methods appear as soon as you load a Makie backend.

Installation

using Pkg
Pkg.develop(path = "path/to/CustomTokenizer")
Pkg.add("CairoMakie")      # optional, for the figures
